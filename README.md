# iasds.github.io

Personal homepage built with Hugo + custom `iasds` theme.

## Structure

```
content/
├── i2p/       # I2P research section
├── qubes/     # Qubes OS research section
└── other/     # Other projects
```

- `_index.md` in each section → homepage card content
- Extra `.md` files → detail pages, auto-listed under the card

## Develop

```bash
hugo server -D
```
